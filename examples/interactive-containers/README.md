# Rhino FCP Examples - Interactive Containers
This folder contains examples for using Rhino FCP's Interactive Containers capability.

## Table of Contents
- [interactive-3d-slicer](./interactive-3d-slicer/README.md) - Run an interactive container session with 3D Slicer to view and/or annotate remote DICOM data on a Rhino Client
- [interactive-3d-slicer-with-extensions](./interactive-3d-slicer-with-extensions/README.md) - Run a custom interactive container session of 3D Slicer with extensions so a user can view and/or annotate remote DICOM data on a Rhino Client
- [interactive-jupyter-and-ollama](./interactive-jupyter-and-ollama/README.md) - Run an interactive Jupyter Notebook session alongside a background Ollama service, to explore a dataset and interact with an LLM model via Ollama.
- [interactive-jupyter-notebook](./interactive-jupyter-notebook/README.md) - Run an interactive container session with Jupyter Notebook to interact with remote data on a Rhino Client
- [interactive-libre-office](./interactive-libre-office/README.md) - Use Office (e.g. spreadsheets) to interact with remote data on a Rhino Client.
- [interactive-llm-inference](./interactive-llm-inference/README.md) - Run an interactive Jupyter Notebook session to perform LLM inference on remote data on a Rhino Client, using a model downloaded from HuggingFace and Runtime External Storage
- [interactive-qupath](./interactive-qupath/README.md) - Run an interactive container session with QuPath to view and/or annotate remote DICOM data on a Rhino Client
