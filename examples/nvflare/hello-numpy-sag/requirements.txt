nvflare==2.6.0
# Pinned to 2.6.0, not a newer release: FCP's server-side NVFlare provisioning only has
# templates up to and including 2.6 (there is no CodeTypes value newer than
# NVIDIA_FLARE_V2_6 on the platform). A container running a newer NVFlare fails on FCP
# with confusing, indirect errors (e.g. missing 'target' in server config, or
# "No module named 'nvflare.app_common.logging.log_receiver'") since FCP generates a
# v2.6-era startup kit that no longer matches a newer NVFlare's expectations. This is
# a platform-wide constraint, not specific to this example.
#
# numpy and protobuf are pulled in automatically as compatible nvflare dependencies.
# (Older pins of numpy<1.23 and protobuf<3.21 were required for nvflare==2.0.5 and
# are no longer needed / no longer installable on current Python versions.)
