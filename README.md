# Rhino FCP User Resources
This is a collection of resources designed to help developers learn and use the Rhino Federated Computing Platform (FCP).

## Table of Contents
- [Examples](./examples/README.md) - specific examples for using generalized compute, interactive containers, NVFlare, and the Rhino Python SDK.
- [Infrastructure](./infrastructure/README.md) - terraform scripts for Rhino clients
- [Tutorials](./tutorials/README.md) - end-to-end guides that walkthrough how to use the platform
- [Utils](./utils/README.md) - commonly used Rhino FCP utilities
