# Advanced Tutorials for Rhino FCP

Deeper dives into specific Rhino FCP capabilities, once you've completed the [Foundational Tutorials](../0_Foundational/). Each subfolder below is a topic area, covered independently - pick whichever is most relevant to what you're building rather than working through them in order.

## Topics

### [0_Configuration](./0_Configuration/)
*(in development)*

### [1_Data_Engineering](./1_Data_Engineering/)

* [`0_intro_to_data_engineering/`](./1_Data_Engineering/0_intro_to_data_engineering/): A 9-part, end-to-end foundational data engineering workflow. Shows how to get data onto the Rhino client, dataset registration and schema generation, federated data discovery, data preparation via Code Objects, OMOP harmonization, OMOP validation, feature engineering, cohort selection, and using the Rhino MCP Server for AI-assisted data engineering.

### [2_Data_Harmonization](./2_Data_Harmonization/)

### [3_Data_Science](./3_Data_Science/)
Federated model training and analysis:
- [`0_intro_to_federated_learning/`](./3_Data_Science/0_intro_to_federated_learning/) - A 3-part introduction to federated learning: the core concepts and motivation, converting existing PyTorch code into an NVFlare federated workflow via simulation, and deploying federated learning for real on the Rhino FCP (a drug-discovery/DeepChem scenario).
- [`federated_imaging_breastMNIST/`](./3_Data_Science/federated_imaging_breastMNIST/) - An end-to-end federated imaging demo (dataset registration, federated descriptive statistics, k-anonymization, and NVFlare model training) using the public BreastMNIST dataset.
