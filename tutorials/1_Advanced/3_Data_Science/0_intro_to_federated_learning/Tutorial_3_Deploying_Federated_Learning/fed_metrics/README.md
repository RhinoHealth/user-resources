# Federated Metrics with the Rhino SDK

## Goal
In this section, we show the user some of the tools available to interact with data living within a project on the Rhino FCP. The user will learn how to conduct statisical analysis on decentralized datasets with pre-built python functions. In this tutorial, the user will analyze the AUC performance of each model trained through out this tutorial to visualize the impact federated learning has on real world data. Furthermore, the user will upload this visualization to the project within the Rhino FCP, enabling collaborators to also view the results.

## Content
A notebook has been prepared to walk the user through an introduction to the Rhino SDK, `notebooks/metrics.ipynb`. Instructions for this portion the tutorial can be found directly embedded within the notebook.
