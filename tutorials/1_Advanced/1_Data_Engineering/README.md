# Data Engineering

## [0_intro_to_data_engineering](./0_intro_to_data_engineering/)

A realistic, end-to-end data engineering workflow on the Rhino FCP, in 9 parts:

- **Tutorial 0 - Getting Data Onto the Client** - transfer your CSV files to the Rhino client (skip if your data is already there)
- **Tutorial 1 - Dataset Registration & Schema Generation** - tell the platform your data exists and describe its structure
- **Tutorial 2 - Data Discovery via Federated Analytics** - explore your registered datasets with aggregate-only statistical queries
- **Tutorial 3 - Data Preparation via Code Objects** - clean and standardize your data with Python Code Objects
- **Tutorial 4 - Harmonization with the Rhino Data Harmonization Engine (RhinoDHE)** - map your data to OMOP CDM target tables
- **Tutorial 5 - OMOP Validation** - verify your harmonized data actually conforms to the OMOP standard
- **Tutorial 6 - Feature Engineering** - derive patient-level features into a single ML-ready feature table
- **Tutorial 7 - Cohort Selection** - derive targeted patient cohorts from the feature table
- **Tutorial 8 - The Rhino MCP: AI-Assisted Data Engineering** - do the above through natural-language prompts in an MCP-compatible AI client, instead of SDK notebook calls
