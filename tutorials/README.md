# Rhino FCP Tutorials
This folder contains guided, hands-on tutorials for learning the Rhino Federated Computing Platform (FCP) - each one walks you through a specific workflow step by step, rather than just providing a working reference implementation to copy from (see `../examples/` for those).

Tutorials are organized progressively, from a first introduction to FCP through to advanced, topic-specific workflows.

## Structure
- **`0_Foundational/`** - Start here if you're new to FCP. Covers core end-to-end workflows: setting up a project, importing data, defining schemas, running code, and analyzing results with the SDK.
- **`1_Advanced/`** - Deeper dives into specific FCP capabilities, once you've completed the foundational tutorials. Each subfolder is a specific topic area.

Each tutorial folder has its own `README.md` with tutorial-specific prerequisites, setup, and step-by-step instructions - start there once you've picked a tutorial to work through.

## Suggested path
1. Complete both `0_Foundational/` tutorials in order (Tutorial 1, then Tutorial 2).
2. Move on to whichever `1_Advanced/` topic is most relevant to what you're building.
