# Tutorials

Welcome to the Rhino Health Federated Computing Platform (FCP) tutorials. Content is organised by **platform functionality** — choose the area that matches what you want to accomplish.

---

## Where to start

**New to Rhino FCP?** Start with the Foundational tutorials — they walk you through the core platform end-to-end before moving on to capability-specific content.

**Already onboarded?** Jump straight to the Advanced section for the area you are working in.

---

## Foundational

| Tutorial | What you'll learn |
|---|---|
| [Tutorial 1 — Hello World: Basic Usage](./foundational/tutorial_1/) | Set up a project, import DICOM data, run a GC and NVFlare code object, analyse results |
| [Tutorial 2 — Data Harmonization via SDK](./foundational/tutorial_2/) | Install and configure the Rhino SDK, import multi-site CSV datasets, run a harmonization workflow |
