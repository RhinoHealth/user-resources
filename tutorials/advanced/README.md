# Advanced / Golden Tutorials

Capability-specific tutorials for the Rhino FCP. Each folder is self-contained — pick the area relevant to your work.

---

## Folder structure

```
advanced/
│
├── installation/               ← set up your local environment, credentials, and node
├── workspace_setup/            ← set up your project, data, and collaborators
├── data_engineering/           ← transform, harmonize, and standardize distributed data
├── federated_data_science/     ← run analytics, train models, and evaluate results across sites
│   ├── federated_analytics/
│   ├── federated_training/
│   └── federated_evaluation/
├── secure_model_sharing/       ← encrypt and protect model code and weights
└── agentic_AI/                 ← run federated workflows through natural language and AI agents
```

---

## Prerequisites

All advanced tutorials assume you have completed at least [Tutorial 1](../foundational/tutorial_1/) or have equivalent hands-on experience with Rhino FCP projects, datasets, and code objects.
