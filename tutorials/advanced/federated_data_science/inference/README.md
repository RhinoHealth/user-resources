# Inference

Run inference using trained model weights across GC and NVFlare code objects on the Rhino FCP.

## What you will learn

- Loading trained model weights from a completed federated training run
- Configuring and running a GC inference code object
- Configuring and running an NVFlare inference job using `infer.py`
- Retrieving and interpreting inference outputs
