# Federated Analytics

Run exploratory data analysis and calculate statistics across distributed sites without moving data.

---

## Notebooks

All analytics notebooks are in [`../../../../examples/rhino-sdk/`](../../../../examples/rhino-sdk/).

| Notebook | What it covers |
|---|---|
| [`eda.ipynb`](../../../../examples/rhino-sdk/eda.ipynb) | Federated EDA — distributions, summaries, cross-site comparisons |
| [`metrics_examples.ipynb`](../../../../examples/rhino-sdk/metrics_examples.ipynb) | Chi-square, t-test, ANOVA, odds ratio, and more |
| [`aggregate_quantile_example.ipynb`](../../../../examples/rhino-sdk/aggregate_quantile_example.ipynb) | Quantile aggregation with differential privacy |
| [`cox.ipynb`](../../../../examples/rhino-sdk/cox.ipynb) | Cox proportional hazards regression |
| [`federated_join/Federated Join Tutorial.ipynb`](../../../../examples/rhino-sdk/federated_join/Federated%20Join%20Tutorial.ipynb) | Inner, left, and full outer joins across sites |
