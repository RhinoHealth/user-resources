# Retrieving SFTP & ECR Credentials

This tutorial shows you how to retrieve your SFTP and ECR credentials from the Rhino FCP platform and configure them locally.

## What you will learn

- Where to find your SFTP credentials in the FCP UI
- Where to find your ECR credentials and workgroup repository name
- How to log in to ECR using the AWS CLI
- How to verify your credentials are working
