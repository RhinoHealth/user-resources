# Configuring your Environment & SDK Setup

This tutorial walks you through setting up your local environment to work with the Rhino FCP Python SDK.

## What you will need

- Python 3.8+
- Docker
- A Rhino FCP account with access to at least one site

## Steps

1. Install the Rhino Python SDK
2. Configure your authentication credentials
3. Set required environment variables
4. Verify connectivity to the FCP
