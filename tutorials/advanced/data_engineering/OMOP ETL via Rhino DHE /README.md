# OMOP ETL via Rhino DHE

This tutorial walks through mapping source clinical data to the OMOP Common Data Model (CDM) using the Rhino Data Harmonization Engine (RhinoDHE).

## What you will learn

- How to configure a RhinoDHE OMOP pipeline
- How to map source fields to OMOP target tables
- How to run and validate the ETL
