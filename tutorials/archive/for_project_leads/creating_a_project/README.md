# 01 — Creating a Project

This tutorial covers the initial setup of a federated project on the Rhino Health Federated Computing Platform (FCP). It is intended for project leads responsible for setting up a new collaboration.

For a general introduction to FCP concepts and terminology, review the [platform orientation](../../platform_orientation/README.md) before proceeding.

---

## What you will learn

1. How to create a new federated project and configure its settings
2. How to define the datasets in scope and review data metrics across sites

---

## Prerequisites

- An active [FCP account](https://dashboard.rhinofcp.com/login) with project lead permissions
- At least one site confirmed as a participant in your project

---
