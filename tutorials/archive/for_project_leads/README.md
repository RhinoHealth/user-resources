# Tutorials for Project Leads

These tutorials are intended for the person managing a federated project. If you are responsible for creating projects, inviting collaborators, defining permissions, and orchestrating runs across sites, you are in the right place.

If you are new to FCP and have not yet reviewed the platform orientation, start there first: [Platform orientation](../platform_orientation/README.md)

---

## Tutorials

### [01 — Creating a project](./creating_a_project/README.md)

How to create a new federated project, configure its settings, and define the sites and datasets in scope.

### [02 — Inviting collaborators and setting permissions](./inviting_collaborators)

How to invite collaborators to a project, assign roles, and manage access permissions across sites.

### [03 — Running and monitoring code](./running_and_monitoring_code)

How to review and approve Code Objects, initiate runs across sites, and monitor progress and results.

### [04 — Managing project lifecycle](./managing_project_lifecycle)

How to manage a project through its full lifecycle, including versioning, archiving, and offboarding collaborators.
