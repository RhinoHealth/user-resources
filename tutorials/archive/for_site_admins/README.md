# Tutorials for Site Admins & IT Administrators

This section provides operational guides for IT and infrastructure staff responsible for the Rhino node at a collaborating institution. Content covers node deployment, site validation, network configuration, and access management. No prior familiarity with FCP is assumed; Python experience is not required.

If you are new to FCP and have not yet reviewed the platform orientation, start there first: [Platform orientation](../platform_orientation/README.md)

---

## Tutorials

### [01 — Deploying and configuring a Rhino node](./deploying_rhino_node)
How to deploy the Rhino node at your institution and configure it for a federated project.

### [02 — Running the site validation script](./site_validation)
How to run the site validation script to confirm your node is correctly installed and able to participate in a project.

### [03 — ECR setup and container registry configuration](./ecr_setup)
How to configure your institution's ECR and connect it to the Rhino node for container image management.

### [04 — Network and firewall requirements](./network_and_firewall)
Reference documentation covering the network and firewall configuration required for a Rhino node deployment.

### [05 — SSO and user access management](./sso_and_user_access)
How to configure SSO and manage user access at your site.
